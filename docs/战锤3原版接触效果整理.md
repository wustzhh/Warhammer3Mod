# 战锤3原版接触效果（Contact Effect）整理

> 接触效果本质是命中时施加的 `special_ability_phases`（多为 negative phase）。
> 收录范围：被 `melee_weapons.contact_phase` / `projectiles.contact_stat_effect` / `imbue_contact` /
> `projectile_explosions.contact_phase_effect` / `special_ability_contact_phase_groups` 引用，
> 或 key 含 `contact` 的 phase。
> 中文名优先 `special_ability_phases_onscreen_name_*`（CN），缺失时用英文。
> 共 **78** 条。文档日期：2026-07-28。

---

## 1. 机制速查

| 挂载位置 | 字段 | 说明 |
|----------|------|------|
| 近战武器 | `melee_weapons.contact_phase` | 近战命中附加 |
| 投射物 | `projectiles.contact_stat_effect` | 投射命中附加 |
| 能力 phase | `special_ability_phases.imbue_contact` | 该 phase 存续期间，攻击附带另一接触 phase |
| 爆炸 | `projectile_explosions.contact_phase_effect` | 爆炸命中附加 |
| 涡流 | `battle_vortexs.contact_effect` | 涡流接触附加（可为任意 phase） |
| 接触组 | `special_ability_contact_phase_groups` | 多接触效果编组 |

相关单位属性：`ignore_imbue_contact_effects_enemy`（免疫敌方接触）、`ignore_imbue_contact_effects_ally`（忽略友方接触）。

**与 unit_attributes 的区别：** 接触效果是 phase，**允许** MOD 新建自定义接触 phase；`unit_attributes` 禁止新增。
